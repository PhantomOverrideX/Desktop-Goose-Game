# Desktop-Goose-Game
A super fun and not at all annoying goose friend

To run it with default settings use the command
python Goose.py

You can add flags to customize the game.

--no-mouse
--no-minimize
--no-edge
--no-poop
--no-context
--no-hud
--no-drag
--click-release
--stage {0,1,2,3,4}
--chaos {1,2,3}                   1 gentle, 2 default, 3 full goose
--minutes MINUTES
--sound
--sprite SPRITE                   path to a PNG of your goose (faces right)
--sprite-shrink SPRITE_SHRINK     shrink the PNG by this whole-number factor (default 2)
